# Zeya — Reference Images

Bu klasör Zeya'nın **ana karakter referans görsellerini** içerir.

Buraya mümkünse:
- Karakter referans sheet'i
- Ön görünüş
- Profil
- 3/4 açı
- Tam boy
- Yüz yakın planı
- Farklı ifadeler

gibi karakter tutarlılığını korumaya yardımcı olan görseller eklenmelidir.

Bu klasördeki görseller, yeni Zeya görselleri üretilirken **ana görsel referans** olarak kabul edilir.

Önerilen isimlendirme:

- `zeya-character-sheet-v1.png`
- `zeya-face-reference-v1.png`
- `zeya-full-body-reference-v1.png`

Karakter görünümünde önemli bir değişiklik yapılırsa yeni versiyon oluşturulmalıdır; eski ana referanslar silinmemelidir.
