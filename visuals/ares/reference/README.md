# Ares — Reference Images

Bu klasör Ares'in **ana karakter referans görsellerini** içerir.

Buraya mümkünse:
- Karakter referans sheet'i
- Ön görünüş
- Profil
- 3/4 açı
- Tam boy
- Yüz yakın planı
- Farklı ifadeler

gibi karakter tutarlılığını korumaya yardımcı olan görseller eklenmelidir.

Bu klasördeki görseller, yeni Ares görselleri üretilirken **ana görsel referans** olarak kabul edilir.

Önerilen isimlendirme:

- `ares-character-sheet-v1.png`
- `ares-face-reference-v1.png`
- `ares-full-body-reference-v1.png`

Karakter görünümünde önemli bir değişiklik yapılırsa yeni versiyon oluşturulmalıdır; eski ana referanslar silinmemelidir.
